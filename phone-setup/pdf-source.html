2. 관리자: 토픽 이름 찾기 (둘 중 하나)

방법 A — 웹앱 병원 화면에서 (추천)

  1. PC 에서 Chrome 을 열고 웹앱 주소를 엽니다.
    https://script.google.com/macros/s/AKfycbz-AdqsI0QU7ExhjOUC4_ULq8Das9895_s19KK65fi9wDRY7jpSte-YJr-u-ykqiJgvZg/exec
  2. 🏥 병원 선택 → 병원명은 아무거나(예: 관리자PC) · 지역 선택 · 접속 코드 입력 → 시작하기
  3. 위쪽 📱 화면이 꺼져도 알림 받기 상자 맨 아래 줄을 봅니다: 토픽: 서울 = par-xxxxxxxxxxxxxxxx-1
  4. = 뒤의 par-…-1 부분만 마우스로 끌어 선택 → Ctrl+C
상자가 안 보이면 이 브라우저에서 예전에 확인 — 이 안내 숨기기를 누른 것입니다. Ctrl+Shift+N (시크릿 창)으로 다시 열거나 방법 B 를 쓰세요.

방법 B — Apps Script 편집기에서

  1. Apps Script 프로젝트 Emergency ntfy 열기
  2. 왼쪽 ⚙ 프로젝트 설정 → 아래 스크립트 속성 → NTFY_PREFIX 값 복사
  3. 값 뒤에 -1 을 붙입니다. 예: par-xxxxxxxxxxxxxxxx-1

지역 번호: 서울 -1 · 인천 -2 · 경기 -3 · 기타 -4. 도구에는 어느 지역 토픽을 넣어도 됩니다 (지역은 다음 단계에서 고름).

3. 관리자: 복원 파일 만들기

  1. 파일 탐색기에서 Desktop\emergency-ntfy\phone-setup\ 폴더를 엽니다.
  2. make-ntfy-restore.html 을 더블클릭 → 브라우저에 🔔 ntfy 복원 파일 만들기 화면이 열립니다.
    (메모장 등으로 열리면: 오른쪽 클릭 → 연결 프로그램 → Chrome)
  3. 토픽 이름 칸 클릭 → Ctrl+V (ntfy://ntfy.sh/par-…-1 처럼 주소째 넣어도 됨)
  4. 받을 지역을 체크합니다 (기본은 서울만 체크, 여러 개 가능).
  5. 복원 파일 만들기 (다운로드) 클릭
  6. 초록색 ✅ ntfy-병원설정-서울.json 다운로드됨 이 나오면 성공 → PC 의 다운로드 폴더에 저장됨
    빨간 "형식이 맞지 않습니다" 가 나오면 par-…-숫자 만 다시 복사해서 붙여넣기
  7. (확인) 파일 내용 미리 보기를 열면 지역마다 "instant": true, "insistent": 1 이 있어야 합니다.

이 도구는 인터넷 없이 PC 안에서만 동작하며, 입력한 토픽을 어디에도 보내지 않습니다.

4. 관리자: 휴대폰으로 파일 보내기

방법절차
카카오톡 PC나와의 채팅에 파일을 끌어다 놓기 → 휴대폰 카카오톡에서 파일 누르기 → 저장
이메일나에게 첨부해서 보내기 → 휴대폰에서 첨부파일 다운로드
USB 케이블휴대폰을 PC 에 연결 → 휴대폰 Download 폴더에 복사

어느 방법이든 휴대폰의 다운로드(Download) 폴더에 들어가면 됩니다. 같은 지역 병원이라면 파일 하나를 여러 휴대폰에 그대로 써도 됩니다.

⚠️ 이 파일에는 토픽 이름이 들어 있습니다. 토픽을 아는 사람은 누구나 알림을 받을 수 있으니 병원에만 전달하고, 단체방 · GitHub 등 공개된 곳에 올리지 마세요.

6. 병원 휴대폰: ntfy 설치와 복원

  1. Play 스토어에서 ntfy 설치 (무료, 회원가입 없음) → 한 번 열기 → 알림 허용을 물으면 허용
  2. ntfy 위쪽 배터리 최적화 안내 → 지금 수정하기 → 허용
    안내가 없으면: 설정 → 애플리케이션 → ntfy → 배터리 → 제한 없음(또는 최적화하지 않음)
    삼성 일부 기종: 설정 → 배터리 → 백그라운드 사용 제한 → 절전 예외 앱에 ntfy 추가
  3. 받은 ntfy-병원설정-….json 을 휴대폰 다운로드 폴더에 저장 (4번 참고)
  4. ntfy 오른쪽 위 ⋮ → 설정 → 맨 아래 백업 및 복원 → 파일에서 복원
  5. 파일 선택 화면에서 다운로드 → 받은 파일 선택 (안 보이면 왼쪽 메뉴 ☰ → 다운로드 / 내 파일)
  6. "복원 성공" 안내 후 첫 화면에 🚑 서울 환자 수용 요청 같은 구독이 보이면 완료
  7. 알림창을 내려 ntfy "알림 수신중 · 즉시 전달 주제 n개 구독중" 알림 확인 (없으면 ntfy 를 닫았다 다시 열기)
이미 같은 토픽을 구독한 휴대폰에서는 그 토픽이 복원되지 않고 건너뜁니다 (기존 시험 휴대폰 A90 · 노트 FE). 복원 파일 설정으로 맞추려면 ntfy 에서 그 구독을 길게 눌러 삭제한 뒤 다시 복원하세요.

7. 병원 휴대폰: 웹앱 병원 등록

  1. 웹앱 링크를 휴대폰의 기본 브라우저(삼성 인터넷 또는 Chrome)로 엽니다.
    병원명 · 접속 코드는 브라우저마다 따로 저장되므로, ntfy 버튼이 여는 브라우저와 같아야 매번 다시 입력하지 않습니다.
  2. 🏥 병원 → 병원명 · 요청을 받을 지역 · 접속 코드 → 시작하기
  3. 첫 화면을 한 번 터치 (그래야 웹앱 소리가 납니다)
  4. 구독 버튼은 누르지 않아도 됩니다 (이미 복원됨) → 확인 — 이 안내 숨기기
  5. 브라우저 메뉴 → 홈 화면에 추가

8. (권장) 알람음을 사이렌으로

복원 파일은 알림 소리를 바꾸지 못하므로, 새로 설치한 휴대폰은 기본 소리로 울립니다. 아래 순서로 사이렌으로 바꿉니다 (약 3분). ntfy 의 계속 울리는 소리는 ntfy 알림 종류 중 "우선순위 최상"의 소리를 씁니다. 이것만 바꾸면 되고 다른 앱 소리는 그대로입니다.

8-1. 사이렌 파일 받기

병원 휴대폰 브라우저에서 아래 주소를 엽니다 → 다운로드 폴더에 저장됩니다.

소리다운로드 주소
천천히 오르내림
(시험 휴대폰에 사용)		https://github.com/bandit1397/emergency-ntfy/raw/main/docs/sounds/siren_wail.ogg
빠른 삐용삐용https://github.com/bandit1397/emergency-ntfy/raw/main/docs/sounds/siren_yelp.ogg

8-2. 알림 소리 폴더로 옮기기 (소리 목록에 바로 나오게)

  1. 내 파일 앱 → 다운로드
  2. siren_wail.ogg 를 길게 누르기 → 이동
  3. 내장 메모리 → Notifications 폴더 → 여기로 이동

8-3. ntfy "우선순위 최상" 소리 바꾸기

  1. 설정 → 애플리케이션 → ntfy → 알림
  2. 우선순위 최상(Max priority) → 소리
  3. 목록에서 siren_wail 선택 → 뒤로 가기 (저장됨)
    목록에 없으면 ＋ / 직접 설정에서 파일을 직접 선택
우선순위 최상 항목이 없으면 아직 최고 우선순위 알림을 한 번도 받지 않은 것입니다 → 시험 요청을 한 번 보낸 뒤 다시 보세요.

8-4. 저장공간 권한 허용 (꼭)

  1. 설정 → 애플리케이션 → ntfy → 권한
  2. 저장공간 → 허용 (안드로이드 13 이상은 음악 및 오디오 → 허용)
⚠️ 이 권한이 없으면 사이렌이 한 번만 울리고 계속 울리지 않습니다 (갤럭시 노트 FE 에서 확인). 그럴 땐 권한을 허용하거나 소리를 기본 알림 소리로 되돌리세요.

8-5. 시험

화면을 끈 상태에서 경찰관 화면으로 시험 요청 → 사이렌이 누를 때까지 계속 울리면 성공 (9번 시험과 함께 해도 됩니다).

참고 — PC 에 USB 로 연결해서 할 때

adb push docs/sounds/siren_wail.ogg /sdcard/Notifications/ adb shell pm grant io.heckel.ntfy android.permission.READ_EXTERNAL_STORAGE adb shell am start -a android.settings.CHANNEL_NOTIFICATION_SETTINGS --es android.provider.extra.APP_PACKAGE io.heckel.ntfy \ --es android.provider.extra.CHANNEL_ID ntfy-max

마지막 명령은 8-3 의 소리 설정 화면을 바로 엽니다 → siren_wail 선택. 두 번째 명령(권한)은 안드로이드 12 이하용이며, 13 이상은 8-4 처럼 휴대폰에서 음악 및 오디오를 허용하세요.

9. 시험 (설정 후 꼭 한 번)

  1. 병원 휴대폰 화면을 끕니다 (무음 모드여도 됨)
  2. 경찰관 화면(다른 휴대폰 또는 PC)에서 그 지역으로 요청 보내기 — 환자 상태에 "시험"이라고 적기
  3. 몇 초 안에 알람이 울리면 성공 (사이렌을 설정했다면 사이렌)
  4. 잠금을 풀고 알림 본문을 누름 → 알람이 멈추고 ntfy 화면이 열리는지
  5. ntfy 화면의 환자 수용 요청 열기 → 웹앱이 병원 화면 그대로 열리는지
  6. 수용 불가 또는 전화 확인으로 응답 → 경찰관 화면에 보이는지 → 경찰관 화면에서 요청 취소
시험 결과원인 · 조치
알림이 아예 안 옴ntfy 에 구독이 있는지 (6) · 인터넷 켜짐 (5) · "알림 수신중" 알림 있는지
1~수 분 늦게 옴구독 → ⋮ → 구독 설정 → 즉시 전달 켜져 있는지
소리 없음 · 한 번만 울림알람 음량 (5) · 구독 설정의 계속 울리기 · 사이렌이면 저장공간 권한 (8)
알림을 눌러도 안 멈춤ntfy 화면을 열어 둔 채 잠갔던 경우 → 10번 참고
웹앱이 설정 화면부터 나옴다른 브라우저로 열림 → 기본 브라우저에서 다시 등록 (7-1)
복원했는데 구독이 안 생김같은 토픽이 이미 있음 → 구독 삭제 후 다시 복원 (6)
"복원 실패"3번에서 만든 .json 파일이 맞는지, 전송 중 이름·내용이 바뀌지 않았는지

10. 🔕 알람 끄는 방법

방법소리
알림 본문 누르기✅ 멈춤 (ntfy 화면이 열림)
ntfy 앱 → 구독한 주제 누르기✅ 멈춤
웹앱의 빨간 응답 대기 중인 요청 배너✅ 멈춤 (ntfy 화면 잠깐 열림 → 뒤로 가기)
웹앱의 수용 가능 / 불가 / 전화 확인✅ 응답 후 멈춤 (ntfy 화면 잠깐 열림 → 뒤로 가기)
알림을 옆으로 밀어 지우기❌ 안 멈출 수 있음
알림의 환자 수용 요청 열기 버튼❌ 웹앱만 열림 → 웹앱 빨간 배너로 끄기
그래도 안 멈출 때설정 → 애플리케이션 → ntfy → 강제 중지 → ntfy 다시 열기 (안 열면 다음 알림을 못 받음)
ntfy 화면을 열어 둔 채로 휴대폰을 잠그지 마세요. 그 상태에서 다음 알람이 오면 잠금을 풀 때 알림만 지워지고 알람은 계속 울립니다. 이때는 ntfy 에서 뒤로 가기 → 구독한 주제를 다시 누르거나 웹앱 배너를 누르세요.

11. ✅ 매일 점검 (근무 시작 때 10초)

휴대폰 충전 중 · Wi-Fi(또는 데이터) 켜짐

알림창에 ntfy "알림 수신중" 알림이 있음 ("Waiting for network" 이면 인터넷 끊김)

알람 음량이 0 이 아님

ntfy 화면이 맨 앞에 열려 있지 않음 (홈 화면이나 웹앱으로 두기)

12. 주의사항

  • 복원 파일(.json)과 토픽 이름은 공개된 곳에 올리지 않습니다. 유출이 의심되면 스크립트 속성 NTFY_PREFIX 를 지우면 다음 요청 때 새 이름이 만들어지고, 병원은 새 복원 파일로 다시 설정해야 합니다.
  • ntfy 알림은 요청을 보낼 때 1번 갑니다 (대신 누를 때까지 계속 울림). 재알림은 없습니다.
  • ntfy.sh 공용 무료 서버에 의존합니다. 서버 장애 시 화면 꺼짐 알림이 멈출 수 있는 시험 운영용입니다.
  • 실제 환자 개인정보(이름, 주민등록번호 등)는 입력하지 마세요. 실제 업무 적용 전 소속 기관의 승인과 개인정보 보호 검토가 필요합니다.
  • 복원 파일 방식은 ntfy 1.25.2 소스로 확인했지만 실제 휴대폰에서는 아직 시험 전입니다. 첫 휴대폰에서 9번 시험을 꼭 해 주세요.
