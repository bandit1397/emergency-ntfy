## 관리자: 복원 파일 만들기 (PC, 1번)

1. [`make-ntfy-restore.html`](make-ntfy-restore.html) 을 PC 에 받아 **더블클릭** (인터넷 필요 없음, 입력 내용은 어디에도 전송되지 않음)
2. **토픽 이름** 칸에 웹앱 병원 화면의 토픽(`par-…-1` 등, 아무 지역 하나)을 붙여넣기
3. 받을 **지역**을 고르고 **복원 파일 만들기** → `ntfy-병원설정-서울.json` 같은 파일이 다운로드됨
4. 이 파일을 병원 휴대폰으로 보내기 (카카오톡 나에게 보내기 · 이메일 · USB)

> ⚠️ 복원 파일에는 **토픽 이름**이 들어 있습니다. 토픽을 아는 사람은 누구나 알림을 받을 수 있으므로
> **GitHub 등 공개된 곳에 올리지 마세요.** (이 폴더의 `.gitignore` 가 `*.json` 을 막아 둡니다.)
> 같은 파일을 여러 병원 휴대폰에 그대로 써도 됩니다 (지역이 같다면).

토픽 이름이 유출됐거나 의심되면 → [설정 절차 PDF](병원휴대폰-설정-절차.pdf) **13번 항목 (마지막 쪽)**:
`NTFY_PREFIX` 지우기 → 새 이름 확인 → 새 복원 파일 → 휴대폰마다 옛 구독 삭제 · 다시 복원 → 시험

## 병원 휴대폰 (대당 약 3분)

1. Play 스토어에서 **ntfy** 설치 → 한 번 열기 → **알림 허용**
2. ntfy 위쪽 **배터리 최적화** 안내 → **지금 수정하기 → 허용**
   (안내가 없으면: 설정 → 애플리케이션 → ntfy → 배터리 → **제한 없음**)
3. 받은 `ntfy-병원설정-….json` 을 휴대폰 **다운로드** 폴더에 저장
4. ntfy → ⋮ → **설정** → 맨 아래 **백업 및 복원** → **파일에서 복원** → 받은 파일 선택
   → "복원 성공" 안내 후 첫 화면에 **🚑 서울 환자 수용 요청** 같은 구독이 보이면 끝
5. 알림창에 ntfy **"알림 수신중 · 즉시 전달 주제 n개 구독중"** 이 떠 있는지 확인 (안 보이면 ntfy 를 한 번 닫았다 열기)
6. 웹앱 링크를 **기본 브라우저**로 열어 🏥 병원 등록 (상위 README 3단계).
   웹앱의 **구독 버튼은 누르지 않아도 됩니다** (이미 구독됨) → **확인 — 이 안내 숨기기**
7. (선택) 사이렌: 상위 README **6. 알람음을 사이렌으로** — 저장공간 권한까지 꼭
8. 상위 README **7. 시험** 으로 화면 꺼짐 · 무음에서 계속 울리는지 확인

### 주의

- **이미 같은 토픽을 구독한 휴대폰**에서는 그 토픽은 복원되지 않고 건너뜁니다 (기존 구독 설정 그대로).
  복원 파일로 다시 맞추려면 ntfy 에서 그 구독을 먼저 길게 눌러 **삭제**한 뒤 복원하세요.
- 복원 파일은 ntfy 의 **앱 전체 설정은 바꾸지 않고** 구독만 추가합니다. "계속 울리기"는 구독마다 켜지므로
  전체 설정의 Keep alerting 이 꺼져 있어도 이 구독은 계속 울립니다.
- 알림 소리는 지금처럼 **"우선순위 최상"(`ntfy-max`) 채널 소리**를 씁니다 (구독별 알림 채널을 만들지 않음).

## 확인한 근거 (ntfy-android v1.25.2 소스)

- 복원 파일 형식: `backup/Backuper.kt` — `magic: "ntfy2586"` 만 검사, 구독마다 `instant` · `insistent` 를 그대로 저장
- 계속 울리기 조건: `msg/NotificationService.kt` — 우선순위 5 이고 (전체 Keep alerting **또는** 구독 `insistent == 1`)
- 이미 있는 토픽: 구독 테이블 insert 가 실패하면 그 구독만 건너뜀 (`applySubscriptions` 의 try/catch)

> 아직 실제 휴대폰에서 복원 파일로 시험하지 않았습니다. 첫 휴대폰에서 위 **8. 시험**을 꼭 해 주세요.
