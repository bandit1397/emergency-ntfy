# 🚑 환자 수용 요청 — ntfy 알림판 (Emergency ntfy)

현장 경찰관이 휴대폰으로 **수용 요청**을 보내면 참여 병원 화면에 바로 표시되고,
병원은 버튼 하나로 **수용 가능 / 수용 불가 / 전화 확인**을 회신하는 웹앱입니다.
병원 휴대폰 화면이 꺼져 있어도 무료 앱 **ntfy**가 **약 2초 안에, 무음 모드에서도 알람처럼, 누를 때까지** 울립니다.

> [Patient-Acceptance-Request](https://github.com/bandit1397/Patient-Acceptance-Request)(Gmail · MacroDroid 알림)와 **별개의 프로젝트**입니다.
> 웹앱 주소, 접속 코드, 데이터가 서로 다릅니다.

- **완전 무료** — Google 계정 하나 + ntfy 공용 서버(ntfy.sh). 회원가입 · API 키 · 광고 · 사용 기간 제한 없음
- **병원 휴대폰 설정 약 15분** — ntfy 앱 설치 → 웹앱의 **구독 버튼** → ntfy 설정 몇 가지 ([상세 안내](#병원-휴대폰-설정-최초-1회-약-15분))
- **자동 삭제** — 응답 대기 요청은 60분, 종료된 요청은 10분 후 자동 삭제

## 동작 방식

```
경찰관 휴대폰 ──요청──▶ Google Apps Script (무료 서버) ◀──응답── 병원 휴대폰/PC
      │          ◀────────── 4초마다 자동 갱신 ──────────▶
      └──(같은 순간)──▶ ntfy.sh ──▶ 병원 휴대폰 ntfy 앱 (화면 꺼짐·무음이어도 알람)
```

- Google Apps Script 서버는 ntfy.sh 에 접속할 수 없어서(Google 차단), **경찰관 휴대폰 브라우저가 직접** ntfy.sh 로 보냅니다.
- ntfy 알림에는 **지역 · 유형 · 요청번호만** 들어가고 환자 상태 문구는 들어가지 않습니다. 알림을 누르면 알람이 멈추고 ntfy 화면이 열리며, 그 화면의 **환자 수용 요청 열기** 버튼으로 웹앱을 엽니다.
  (알림에 웹앱 주소를 바로 연결하면 눌러도 알람이 멈추지 않아서 이렇게 했습니다. ntfy 는 토픽 화면이 새로 열릴 때만 알람을 끕니다.)
- 수용 요청은 지역마다 **최근 3건만** 남고, 새 요청이 오면 가장 오래된 것부터 밀어내서 지웁니다 — 웹앱 목록과 ntfy 앱 모두 (`CONFIG.NTFY_KEEP`).
- 토픽(구독 주소)은 지역마다 하나이고, 서버가 처음 쓸 때 추측하기 어려운 이름을 만들어 **스크립트 속성 `NTFY_PREFIX`** 에 저장합니다 (이 저장소에는 없음).

| 사용자 | 할 수 있는 일 |
|---|---|
| 👮 경찰관 | 환자 유형·지역·상태 입력 → 참여 병원 전체에 요청 → 응답 실시간 확인 → **이송 결정** 또는 취소 |
| 🏥 병원 | 담당 지역 요청 수신 (ntfy 알람 + 웹앱 화면) → 수용 가능/불가/전화 확인 회신 → 이송 결정 확인 |

병원끼리는 서로의 병원명을 볼 수 없고 응답 집계(가능 n곳 등)만 봅니다.

## 설치 (관리자 1회, 약 5분)

1. https://script.google.com 접속 → **새 프로젝트** (이름 예: `Emergency ntfy`)
2. 기본 `Code.gs` 내용을 지우고 이 저장소의 [`Code.gs`](Code.gs) 내용을 붙여넣기
3. 왼쪽 **파일 ＋ → HTML** → 이름을 `Index` 로 만들고 [`Index.html`](Index.html) 내용을 붙여넣기
4. (권장) **프로젝트 설정(⚙) → 스크립트 속성 → 속성 추가** `ACCESS_CODE` = 원하는 숫자/문자 → 처음 접속할 때 이 코드가 필요합니다
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나** · 액세스 권한: **모든 사용자**
6. 권한 승인 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 경찰관·병원에 공유

> 메일 발송 권한이나 트리거 설치(`setup`)는 필요 없습니다.
> 코드를 수정한 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 같은 URL에 반영됩니다.

## 병원 휴대폰 설정 (최초 1회, 약 15분)

안드로이드 휴대폰 기준입니다 (갤럭시 A90 · 안드로이드 12, 갤럭시 노트 FE · 안드로이드 9 에서 확인).
메뉴 이름은 기종 · 안드로이드 버전마다 조금 다를 수 있습니다. 순서대로 따라 하고, 마지막 **7. 시험**까지 꼭 해 주세요.

### 0. 준비물

- 병원에 두고 쓸 **안드로이드 휴대폰** 1대 (아이폰은 계속 울리기가 안 됨 — 아래 한계 참고)
- 관리자에게 받은 **웹앱 링크**(또는 QR)와 **접속 코드**
- **인터넷이 항상 연결된 상태** (Wi-Fi 또는 모바일 데이터) · 가능하면 **충전기에 꽂아 두기**

### 1. 휴대폰 기본 설정

| 항목 | 위치 | 설정 | 이유 |
|---|---|---|---|
| 인터넷 | 화면 위를 내려서 빠른 설정 | **Wi-Fi 또는 모바일 데이터 켜기** (항상) | 꺼져 있으면 알림이 **아예 오지 않음** (시험 중 A90 에서 실제로 겪음) |
| 알람 음량 | 설정 → 소리 및 진동 → 음량 → **알람** | **중간 이상** (0 이면 안 됨) | ntfy 는 **알람 음량**으로 울림. 0 이면 계속 울리기가 시작되지 않음 |
| 무음 · 진동 모드 | — | 상관없음 | 알람 음량으로 울리므로 무음이어도 소리 남 |
| 방해 금지 | 설정 → 알림 → 방해 금지 | 쓰지 않거나, 쓰면 **알람 허용** | 방해 금지 중 알람까지 막으면 안 울림 |
| 화면 잠금 | — | 잠금 있어도 됨 | 잠긴 화면에서도 울리고, 알림은 잠금 화면에서 눌러도 됨 |
| 자동 업데이트 · 재시작 | (선택) 설정 → 디바이스 케어 → 자동 최적화 | 재시작 시간을 근무 외 시간으로 | 재시작 직후 잠깐 연결이 끊길 수 있음 |

### 2. ntfy 앱 설치와 권한

1. Play 스토어에서 **[ntfy](https://play.google.com/store/apps/details?id=io.heckel.ntfy)** 설치 (무료, 회원가입 없음 · 위 QR 코드)
2. ntfy 를 한 번 엽니다. **알림 허용**을 물으면 **허용** (안드로이드 13 이상)
3. ntfy 앱 위쪽에 **배터리 최적화** 안내가 보이면 **지금 수정하기 → 허용**
   - 안내가 없으면: 설정 → 애플리케이션 → ntfy → 배터리 → **제한 없음**(또는 **최적화하지 않음**)
   - 삼성: 설정 → 배터리(및 디바이스 케어) → 백그라운드 사용 제한 → **절전 예외 앱**에 ntfy 추가 (있는 기종만)
4. 설정 → 애플리케이션 → ntfy → **알림** → 알림 허용 **켜짐** 확인

### 3. 웹앱에 병원 등록

1. 받은 **웹앱 링크**를 엽니다
   - ⚠️ **휴대폰의 기본 브라우저**(삼성 인터넷 또는 Chrome)로 여세요. 병원명 · 접속 코드는 **브라우저마다 따로 저장**되므로,
     ntfy 의 버튼이 여는 브라우저와 같아야 매번 다시 입력하지 않습니다. (A90 = 삼성 인터넷, 노트 FE = Chrome 이었음)
2. **🏥 병원** 선택 → **병원명** · **요청을 받을 지역** 선택 → **접속 코드** 입력 → **시작하기**
3. 첫 화면을 한 번 **터치**합니다 (그래야 웹앱 소리가 납니다)
4. 브라우저 메뉴 → **홈 화면에 추가** (삼성 인터넷: ≡ → 현재 페이지 추가 → 홈 화면 / Chrome: ⋮ → 홈 화면에 추가)

### 4. 알림 구독 (ntfy)

1. 웹앱 병원 화면의 **📱 화면이 꺼져도 알림 받기** 안내에서 **🔔 ○○ 구독** 버튼을 누릅니다 → ntfy 가 열리며 구독됨
   - 안 열리면: ntfy 앱 → **＋** → 웹앱 안내 아래쪽의 **토픽 이름**(`par-…-1` 등)을 그대로 입력 → 구독
2. ntfy 첫 화면 **구독한 주제**에 토픽이 보이는지 확인 (지역마다 하나씩)
3. 웹앱에서 **확인 — 이 안내 숨기기** 를 누릅니다

### 5. ntfy 설정 (중요 — 하나라도 빠지면 안 울리거나 늦게 옴)

1. **계속 울리기:** ntfy 첫 화면 ⋮ → **설정** → **Keep alerting for highest priority** → **사용**
   (끄면 무음 모드에서 소리가 안 나고, 울려도 한 번만 울림)
2. **즉시 전달:** ntfy 첫 화면에서 **구독한 주제** 누르기 → ⋮ → **구독 설정** → **즉시 전달** → **사용**
   - 구독한 주제가 여러 개면 **주제마다** 켭니다
   - 끄면 Google(Firebase)을 거쳐 오는데, 시험 중 **몇 분씩 늦거나 안 오는** 일이 있었습니다. 켜면 배터리를 조금 더 씁니다
   - 켜면 알림창에 ntfy 의 **"알림 수신중 · 즉시 전달 주제 1개 구독중"** 알림이 항상 떠 있습니다 (정상)
   - 이 알림이 **"Waiting for network"** 로 바뀌어 있으면 **인터넷이 끊긴 것**입니다 → Wi-Fi/데이터 확인
3. (권장) **사이렌 소리** — 아래 **6. 알람음을 사이렌으로**

### 6. 알람음을 사이렌으로 (권장)

ntfy 의 계속 울리는 소리는 ntfy 알림 종류 중 **"우선순위 최상"의 소리**를 그대로 씁니다. 이것만 바꾸면 되고, 다른 앱 알림이나 벨소리는 바뀌지 않습니다.

| 소리 | 파일 | 느낌 |
|---|---|---|
| Emergency Siren (wail) | [siren_wail.ogg](docs/sounds/siren_wail.ogg) | 구급차 · 민방위처럼 천천히 오르내림 (시험 휴대폰에 사용) |
| Emergency Bell (fast) | [siren_yelp.ogg](docs/sounds/siren_yelp.ogg) | 빠르게 삐용삐용 반복 |

1. 병원 휴대폰에서 위 파일 링크를 열고 **다운로드** (각 약 30KB)
2. 설정 → 애플리케이션 → ntfy → **알림** → **"우선순위 최상"** → **소리**
3. 목록에서 받은 사이렌을 고릅니다 (목록에 없으면 **직접 설정** 에서 다운로드한 파일 선택) → **뒤로 가기**로 저장
4. 설정 → 애플리케이션 → ntfy → **권한** → **저장공간**(파일 및 미디어 · 음악 및 오디오) → **허용**
5. 아래 **7. 시험**으로 사이렌이 **누를 때까지 계속** 울리는지 확인

> ⚠️ ntfy 에 **저장공간 권한이 없으면** 사이렌이 알림과 함께 **한 번만** 울리고, 계속 울리는 알람은 **아예 시작되지 않습니다.**
> (갤럭시 노트 FE · 안드로이드 9 에서 확인. 휴대폰에 받은 소리 파일을 ntfy 가 읽지 못해서입니다.)
> 시험에서 한 번만 울리고 멈추면 저장공간 권한을 허용하거나, 소리를 **기본 알림 소리**로 되돌리세요.

> 소리는 [make_sirens.py](docs/sounds/make_sirens.py) 로 직접 합성한 것이라 저작권 문제가 없습니다.
> PC 에 연결한 경우 `adb push siren_wail.ogg /sdcard/Notifications/` 로 넣으면 소리 목록에 바로 나타납니다.

### 7. 시험 (설정 후 꼭 한 번)

1. 병원 휴대폰 **화면을 끕니다** (무음 모드여도 됩니다)
2. 경찰관 화면(다른 휴대폰 또는 PC)에서 그 지역으로 **요청 보내기** — 환자 상태에 "시험"이라고 적기
3. **몇 초 안에** 알람이 울리면 성공 (사이렌을 설정했다면 사이렌)
4. 잠금을 풀고 **알림 본문을 누릅니다** → 알람이 **멈추고** ntfy 화면이 열리는지
5. ntfy 화면의 **환자 수용 요청 열기** → 웹앱이 열리고 **병원 화면 그대로**(다시 설정하라고 안 나옴)인지
6. **수용 불가** 또는 **전화 확인**으로 응답 → 경찰관 화면에 응답이 보이는지 → 경찰관 화면에서 **요청 취소**

| 시험 결과 | 원인 · 조치 |
|---|---|
| 알림이 아예 안 옴 | ntfy **구독한 주제**가 있는지 (4) · **인터넷** 켜짐 (1) · **즉시 전달** (5-2) |
| 1~수 분 늦게 옴 | **즉시 전달** 켜기 (5-2) |
| 알림은 오는데 소리 없음 · 한 번만 울림 | **Keep alerting** (5-1) · **알람 음량** (1) · 사이렌이면 **저장공간 권한** (6-4) |
| 알림을 눌러도 안 멈춤 | ntfy 화면을 열어 둔 채 잠갔던 경우 → 아래 **알람 끄기** 3번 참고 |
| 웹앱이 다시 설정 화면부터 나옴 | 다른 브라우저로 열린 것 → 기본 브라우저에서 다시 등록 (3-1) |

### 🔕 알람 끄기

1. 울리는 **알림을 누릅니다** → 알람이 멈추고 ntfy 화면이 열립니다
2. ntfy 화면의 **환자 수용 요청 열기** 버튼을 누르면 웹앱이 열립니다 → 수용 가능/불가 회신
3. **ntfy 화면을 열어 둔 채로 휴대폰을 잠그지 마세요.** 그 상태에서 다음 알람이 오면, 잠금을 풀 때 ntfy 가 알림을 지워 버리고
   알람은 계속 울립니다 (ntfy 앱 동작). 이때는 ntfy 에서 뒤로 가기 → 구독한 주제를 다시 누르거나, 웹앱 배너를 누르세요.

| 방법 | 소리 |
|---|---|
| **알림 본문 누르기** | ✅ 멈춤 |
| ntfy 앱 → 구독한 주제 누르기 | ✅ 멈춤 (알람은 ntfy 의 이 화면이 열릴 때 멈춥니다) |

## 설정 변경

`Code.gs` 맨 위 `CONFIG` 에서 바꿀 수 있습니다.

| 항목 | 기본값 | 의미 |
|---|---|---|
| `REQUEST_TTL_MIN` | 60 | 응답 대기 요청 자동 삭제(분) |
| `DONE_KEEP_MIN` | 10 | 종료된 요청 결과 표시 시간(분) |
| `TYPES` | 주취자, 정신응급, 일반응급, 외상, 기타 | 환자 유형 |
| `REGIONS` | 서울, 인천, 경기, 기타 | 지역 (순서대로 토픽 번호 1~4) |
| `NTFY_SERVER` | `https://ntfy.sh` | ntfy 서버 (직접 운영하는 서버로 바꿀 수 있음) |
| `NTFY_KEEP` | 3 | 지역별로 남길 최근 수용 요청 수 (웹앱 목록 · ntfy 앱) |

모든 요청을 즉시 지우려면 Apps Script 편집기에서 `clearAll` 함수를 선택해 **실행**합니다.
토픽 이름을 바꾸려면(유출 의심 시) 스크립트 속성 `NTFY_PREFIX` 를 지우면 다음 요청 때 새 이름이 만들어집니다 — 병원은 다시 구독해야 합니다.

## 한계와 주의사항

- **재알림이 없습니다.** ntfy 알림은 요청을 보낼 때 1번 갑니다 (대신 누를 때까지 계속 울림). 웹앱 화면이 켜져 있으면 응답할 때까지 3초마다 울립니다.
- 경찰관 휴대폰이 요청 직후 인터넷이 끊기면 ntfy 알림이 빠질 수 있습니다 (요청 자체는 웹앱에 표시됨, 실패하면 경찰관 화면에 안내가 뜸).
- **토픽 이름을 아는 사람은 누구나 알림을 받을 수 있습니다.** 그래서 알림에 환자 정보를 넣지 않습니다. 토픽은 접속 코드를 넣은 병원 화면에서만 보입니다.
- ntfy.sh 공용 서버(무료)에 의존합니다. 서버 장애 시 화면 꺼짐 알림이 멈출 수 있습니다. 무료 서버의 하루 발송 한도 안에서 쓰는 **시험 운영**용입니다.
- "Keep alerting" 소리는 **알림 본문을 눌러야** 멈춥니다. 밀어서 지우거나 알림 버튼을 누르면 계속 울릴 수 있습니다 (ntfy 1.25.2 에서 확인).
- "Keep alerting" 은 안드로이드 ntfy 앱 기능입니다. 아이폰 ntfy 앱은 알림은 오지만 계속 울리지는 않습니다.
- 접속 코드는 간단한 잠금일 뿐, 개인별 인증이 아닙니다.
- **실제 환자 개인정보(이름, 주민등록번호 등)는 입력하지 마세요.** 실제 업무 적용 전에는 소속 기관의 승인과 개인정보 보호 검토가 필요합니다.
