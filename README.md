# 🚑 환자 수용 요청 — ntfy 알림판 (Emergency ntfy)

현장 경찰관이 휴대폰으로 **수용 요청**을 보내면 참여 병원 화면에 바로 표시되고,
병원은 버튼 하나로 **수용 가능 / 수용 불가 / 전화 확인**을 회신하는 웹앱입니다.
병원 휴대폰 화면이 꺼져 있어도 무료 앱 **ntfy**가 **약 2초 안에, 무음 모드에서도 알람처럼, 누를 때까지** 울립니다.

> [Patient-Acceptance-Request](https://github.com/bandit1397/Patient-Acceptance-Request)(Gmail · MacroDroid 알림)와 **별개의 프로젝트**입니다.
> 웹앱 주소, 접속 코드, 데이터가 서로 다릅니다.

- **완전 무료** — Google 계정 하나 + ntfy 공용 서버(ntfy.sh). 회원가입 · API 키 · 광고 · 사용 기간 제한 없음
- **병원 설치 2분** — ntfy 앱 설치 → 웹앱의 **구독 버튼** 한 번
- **자동 삭제** — 응답 대기 요청은 60분, 종료된 요청은 10분 후 자동 삭제

## 동작 방식

```
경찰관 휴대폰 ──요청──▶ Google Apps Script (무료 서버) ◀──응답── 병원 휴대폰/PC
      │          ◀────────── 4초마다 자동 갱신 ──────────▶
      └──(같은 순간)──▶ ntfy.sh ──▶ 병원 휴대폰 ntfy 앱 (화면 꺼짐·무음이어도 알람)
```

- Google Apps Script 서버는 ntfy.sh 에 접속할 수 없어서(Google 차단), **경찰관 휴대폰 브라우저가 직접** ntfy.sh 로 보냅니다.
- ntfy 알림에는 **지역 · 유형 · 요청번호만** 들어가고 환자 상태 문구는 들어가지 않습니다. 알림을 누르면 웹앱이 열립니다.
- 토픽(구독 주소)은 지역마다 하나이고, 서버가 처음 쓸 때 추측하기 어려운 이름을 만들어 **스크립트 속성 `NTFY_PREFIX`** 에 저장합니다 (이 저장소에는 없음).

| 사용자 | 할 수 있는 일 |
|---|---|
| 👮 경찰관 | 환자 유형·지역·상태 입력 → 참여 병원 전체에 요청 → 응답 실시간 확인 → **이송 결정** 또는 취소 |
| 🏥 병원 | 담당 지역 요청 수신 (ntfy 알람 + 웹앱 화면) → 수용 가능/불가/전화 확인 회신 → 이송 결정 확인 |

병원끼리는 서로의 병원명을 볼 수 없고 응답 집계(가능 n곳 등)만 봅니다.

## 설치 (관리자 1회, 약 5분)

1. https://script.google.com 접속 → **새 프로젝트** (이름 예: `Emergency ntfy`)
2. 기본 `Code.gs` 내용을 지우고 이 저장소의 [`Code.gs`](Code.gs) 내용을 붙여넣기
3. 왼쪽 **파일 ＋ → HTML** → 이름을 `Index` 로 만들고 [`Index.html`](Index.html) 내용을 붙여넣기
4. (권장) **프로젝트 설정(⚙) → 스크립트 속성 → 속성 추가** `ACCESS_CODE` = 원하는 숫자/문자 → 처음 접속할 때 이 코드가 필요합니다
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나** · 액세스 권한: **모든 사용자**
6. 권한 승인 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 경찰관·병원에 공유

> 메일 발송 권한이나 트리거 설치(`setup`)는 필요 없습니다.
> 코드를 수정한 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 같은 URL에 반영됩니다.

## 병원 휴대폰 설정 (최초 1회, 2분)

1. 받은 웹앱 링크를 열고 **접속 코드** 입력 → **🏥 병원** → 병원명 · 수신 지역 입력 → 시작
2. Play 스토어에서 **[ntfy](https://play.google.com/store/apps/details?id=io.heckel.ntfy)** 설치 (무료)
3. 웹앱 병원 화면의 **🔔 ○○ 구독** 버튼을 누릅니다 → ntfy 앱이 열리면 구독 완료
   (버튼이 안 열리면 ntfy 앱 ＋ 에서 화면에 표시된 토픽 이름을 직접 입력)
4. ntfy 앱 위쪽 **배터리 최적화** 안내 → **지금 수정하기** → 허용
5. ntfy 앱 첫 화면 ⋮ → **설정** → **Keep alerting for highest priority** 켜기 (알림을 누를 때까지 계속 울림)
6. 웹앱을 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있습니다
7. (권장) 알람음을 **사이렌**으로 바꾸기 — 아래 참고

### 🚨 알람음을 사이렌으로 바꾸기

ntfy 의 계속 울리는 소리는 ntfy 알림 종류 중 **"우선순위 최상"의 소리**를 그대로 씁니다. 이것만 바꾸면 되고, 다른 앱 알림이나 벨소리는 바뀌지 않습니다.

| 소리 | 파일 | 느낌 |
|---|---|---|
| Emergency Siren (wail) | [siren_wail.ogg](docs/sounds/siren_wail.ogg) | 구급차 · 민방위처럼 천천히 오르내림 (시험 휴대폰에 사용) |
| Emergency Bell (fast) | [siren_yelp.ogg](docs/sounds/siren_yelp.ogg) | 빠르게 삐용삐용 반복 |

1. 병원 휴대폰에서 위 파일 링크를 열고 **다운로드** (각 약 30KB)
2. 휴대폰 **설정 → 애플리케이션 → ntfy → 알림 → "우선순위 최상"** → **소리**
3. 목록에서 받은 사이렌을 고릅니다 (목록에 없으면 **직접 설정** 에서 다운로드한 파일 선택) → **뒤로 가기**로 저장
4. **설정 → 애플리케이션 → ntfy → 권한 → 저장공간 → 허용** (아래 주의 참고)
5. 아래 **시험**으로 사이렌이 **누를 때까지 계속** 울리는지 확인

> ⚠️ ntfy 에 **저장공간 권한이 없으면** 사이렌이 알림과 함께 **한 번만** 울리고, 계속 울리는 알람은 **아예 시작되지 않습니다.**
> (2026-10-25 갤럭시 노트 FE · 안드로이드 9 에서 확인. 휴대폰에 받은 소리 파일을 ntfy 가 읽지 못해서입니다.)
> 시험에서 한 번만 울리고 멈추면 저장공간 권한을 허용하거나, 소리를 **기본 알림 소리**로 되돌리세요.

> 소리는 [make_sirens.py](docs/sounds/make_sirens.py) 로 직접 합성한 것이라 저작권 문제가 없습니다.
> PC 에 연결한 경우 `adb push siren_wail.ogg /sdcard/Notifications/` 로 넣으면 소리 목록에 바로 나타납니다.

### 🔕 알람 끄기

1. 울리는 **알림을 누릅니다** → 알람이 멈추고 ntfy 화면이 열립니다
2. ntfy 화면의 **메시지를 한 번 더 누르면** 웹앱이 열립니다 → 수용 가능/불가 회신

| 방법 | 소리 |
|---|---|
| **알림 본문 누르기** | ✅ 멈춤 |
| 알림을 옆으로 밀어 지우기 | ❌ 안 멈출 수 있음 (ntfy 앱 동작) |
| 알림의 버튼(예: 앱 열기) | ❌ 안 멈춤 — 그래서 버튼은 넣지 않았습니다 |
| 그래도 안 멈출 때 | ntfy 앱 열기 → 그래도 안 되면 설정 → 애플리케이션 → ntfy → **강제 중지** 후 **ntfy 다시 열기** (안 열면 다음 알림을 못 받음) |

### 시험

1. 병원 휴대폰 화면을 끕니다 (무음 모드여도 됩니다)
2. 경찰관 화면에서 그 지역으로 **요청 보내기**
3. 몇 초 안에 화면이 켜지고 알람이 울리면 성공 → **알림을 눌러** 알람이 멈추는지 확인

시험 결과 (2026-10-25, 갤럭시 A90 · 안드로이드 12 · ntfy 1.25.2): 화면 꺼짐 · 무음 모드에서 보낸 지 약 1~2초 만에
화면이 켜지고 알람 채널로 소리가 났으며, 알림을 누를 때까지 계속 울렸습니다.
배포된 웹앱으로 처음부터 끝까지(병원 화면 구독 버튼 → 경찰관 요청 → 휴대폰 알람)도 약 1.8초 만에 동작했습니다.

## 설정 변경

`Code.gs` 맨 위 `CONFIG` 에서 바꿀 수 있습니다.

| 항목 | 기본값 | 의미 |
|---|---|---|
| `REQUEST_TTL_MIN` | 60 | 응답 대기 요청 자동 삭제(분) |
| `DONE_KEEP_MIN` | 10 | 종료된 요청 결과 표시 시간(분) |
| `TYPES` | 주취자, 정신응급, 일반응급, 외상, 기타 | 환자 유형 |
| `REGIONS` | 서울, 인천, 경기, 기타 | 지역 (순서대로 토픽 번호 1~4) |
| `NTFY_SERVER` | `https://ntfy.sh` | ntfy 서버 (직접 운영하는 서버로 바꿀 수 있음) |

모든 요청을 즉시 지우려면 Apps Script 편집기에서 `clearAll` 함수를 선택해 **실행**합니다.
토픽 이름을 바꾸려면(유출 의심 시) 스크립트 속성 `NTFY_PREFIX` 를 지우면 다음 요청 때 새 이름이 만들어집니다 — 병원은 다시 구독해야 합니다.

## 한계와 주의사항

- **재알림이 없습니다.** ntfy 알림은 요청을 보낼 때 1번 갑니다 (대신 누를 때까지 계속 울림). 웹앱 화면이 켜져 있으면 응답할 때까지 3초마다 울립니다.
- 경찰관 휴대폰이 요청 직후 인터넷이 끊기면 ntfy 알림이 빠질 수 있습니다 (요청 자체는 웹앱에 표시됨, 실패하면 경찰관 화면에 안내가 뜸).
- **토픽 이름을 아는 사람은 누구나 알림을 받을 수 있습니다.** 그래서 알림에 환자 정보를 넣지 않습니다. 토픽은 접속 코드를 넣은 병원 화면에서만 보입니다.
- ntfy.sh 공용 서버(무료)에 의존합니다. 서버 장애 시 화면 꺼짐 알림이 멈출 수 있습니다. 무료 서버의 하루 발송 한도 안에서 쓰는 **시험 운영**용입니다.
- "Keep alerting" 소리는 **알림 본문을 눌러야** 멈춥니다. 밀어서 지우거나 알림 버튼을 누르면 계속 울릴 수 있습니다 (ntfy 1.25.2 에서 확인).
- "Keep alerting" 은 안드로이드 ntfy 앱 기능입니다. 아이폰 ntfy 앱은 알림은 오지만 계속 울리지는 않습니다.
- 접속 코드는 간단한 잠금일 뿐, 개인별 인증이 아닙니다.
- **실제 환자 개인정보(이름, 주민등록번호 등)는 입력하지 마세요.** 실제 업무 적용 전에는 소속 기관의 승인과 개인정보 보호 검토가 필요합니다.
